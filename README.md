This repository contains projects in which machine learning tools were used to analyse and model process datasets. Each project illustrates the value that machine learning and other statistical tools hold for understanding and modelling process data.

Currently, only one project is in the repository. The other projects are currently being updated. This project can be found under the folder "Process mode identification". The main file for this project is "iron_ore_flotation_process_modes.ipynb", and the associated data is stored in the file "iof_data.zip". 
This project illustrates how data visualisation tools and machine learning methods can be used to derive insights into data for an iron ore flotation process.
